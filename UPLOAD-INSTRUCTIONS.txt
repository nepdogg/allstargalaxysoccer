UPLOAD V224 TO GITHUB

1. Open this V224 folder.
2. Upload the css and js folders to the ROOT of your GitHub repository.
3. Allow GitHub to replace these matching files:
   css/styles.css
   js/script.js
4. Commit the upload.
5. Wait for GitHub Pages deployment to finish.
6. On the website press Ctrl+F5 to bypass the old cached CSS and JavaScript.

This package is installed after V223 and contains only the changed files.
