Automated Desktop + Phone Screenshots

Use the GitHub Actions workflow to open every public page, capture desktop and phone screenshots, and test overflow, broken images, and browser console errors.

Open Visual QA in GitHub ActionsRun Site Diagnostics

How to run it

  1. Open Visual QA in GitHub Actions.
  2. Select Run workflow.
  3. Wait for the green check or open any failed step.
  4. At the bottom of the completed run, download the screenshot/report artifact.
  5. Upload the desktop and phone screenshots here when a visual issue needs troubleshooting.

What this page represents

QA Diagnostics checks website data and assets inside the admin dashboard. Visual QA runs on GitHub servers and creates the desktop/phone screenshot package.
