ALLSTAR GALAXY V230 — LIVE HOMEPAGE FEATURE TOTALS

This update adds automatic live totals to the six signature homepage cards.
The numbers are calculated from data/master-content.json whenever the page loads,
so they update automatically whenever published website content changes.

LIVE CARD TOTALS
- Galaxy Shuffle: direct game and game-award videos available to shuffle
- Search: published searchable games, seasons, playlists, awards, players, and news
- Latest Games: published latest-game cards and their available direct videos
- Game Awards: published award videos
- Best Of: published featured Best Of collections
- Complete Archive: published seasons and media collections

OTHER DETAILS
- Hidden items are excluded.
- Blank links and # placeholders are not counted as videos.
- A graceful "Collection Growing" fallback appears if the data file cannot load.
- Responsive sizing is included for desktop, tablet, and phone layouts.
- No other pages, data, admin features, or homepage structure were changed.

FILES CHANGED / ADDED
- index.html
- css/styles.css
- js/homepage-live-stats.js (new)
