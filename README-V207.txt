ALLSTAR GALAXY V207 — GALAXY SEARCH

Adds a global archive search to every public website page.

Search indexes:
- Games (season, game number, opponent, score/result, date, location)
- Game Awards (when gameAwards data is present)
- Players
- Seasons
- Playlists
- News

Features:
- Search button in the main navigation
- Full-screen responsive search overlay
- Instant results while typing
- Filters for Games, Awards, Players, Seasons, Playlists, and News
- Direct Full Match, Highlights, Slideshow, Award Video, and Playlist links
- Keyboard shortcut: Ctrl+K / Command+K
- Phone and desktop layouts

The code-only update does not include or overwrite master-content.json or graphics.
