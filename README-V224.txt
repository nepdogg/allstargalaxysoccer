ALLSTAR GALAXY V224

This cumulative update fixes the issues reported after V223:

1. Explore the Galaxy colors
   - Team: purple
   - Schedule: green
   - News: orange
   - Follow: pink
   - Media remains blue, Galaxy Shuffle remains gold, Live remains red.

2. Homepage Latest Games carousel
   - Changes the carousel frame, arrows, dots, active card glow and media counter from blue to homepage gold.
   - Enlarges the three bottom information fields so Season/Game, Teams and Result/Score better fill their spaces.

3. Galaxy Shuffle popup
   - Fixes the Galaxy Shuffle button inside an opened game popup.
   - The button now immediately selects and plays another random available video from that same game.
   - It avoids replaying the same video consecutively when more than one is available.
