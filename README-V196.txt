ALLSTAR GALAXY WEBSITE V196 — GAME AWARDS

Added a responsive current-season Game Awards carousel to the Media page.
Added a Game Awards Admin page for phone and PC.

Admin workflow:
1. Select an existing game.
2. Select Player, Goal, Assist, Save, or Play of the Game.
3. Select a player.
4. Paste the YouTube video URL.
5. Save and Publish All Changes.

The public card automatically uses the game season, number, opponent, result, player name, jersey number, position, and photo. Award colors and icons are applied automatically. Only awards linked to the newest visible award season appear in the carousel, so a new season takes over automatically after its first award is added.
